# AutoGest

Proyecto final desarrollado en Flutter.

## Descripción
AutoGest es una aplicación móvil orientada a la gestión vehicular. Este proyecto incluye autenticación, conexión a API, manejo de tokens, estructura modular y base para los diferentes módulos del sistema.

## Tecnologías usadas
- Flutter
- Dart
- Dio
- Shared Preferences
- Image Picker
- Cached Network Image
- Flutter HTML
- YouTube Player Flutter
- Carousel Slider
